## Navigation Features

### Desktop Navigation:
- Fixed left sidebar (250px width)
- Smooth hover states on nav links
- Active section indicator (sage green)
- Navigation tracks scroll position automatically

### Mobile Navigation:
- Click hamburger menu (☰) to toggle
- Menu slides in from top
- Click a section to navigate (menu auto-closes)
- Click outside to close menu

### Keyboard Navigation:
- **Tab** - Move to next interactive element
- **Shift + Tab** - Move to previous element
- **Enter/Space** - Activate buttons
- **ESC** - Close modals
