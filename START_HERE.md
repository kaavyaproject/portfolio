## 💡 Customization Tips

### To Change Colors
Edit the CSS variables in `style_boho.css`:
```css
--color-primary: #cfa58a;    /* Change to your preferred color */
--color-accent: #7a9e82;     /* Change accent color */
```

### To Add More Skills
Add to `skillDescriptions` in `script.js`:
```javascript
'new-skill': {
  title: "Your Skill",
  description: "Description here",
  usage: "Usage context here"
}
```

### To Adjust Spacing
Modify spacing variables:
```css
--spacing-lg: 2rem;   /* Increase for more space */
--spacing-xl: 2.5rem; /* Adjust as needed */
```
