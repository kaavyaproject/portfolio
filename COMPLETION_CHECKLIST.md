### Viewing:
1. Open `index.html` in web browser
2. Navigate using sidebar or hamburger menu
3. Interact with skills, projects, and forms

### Customizing:
1. Edit HTML content in `index.html`
2. Adjust colors in CSS variables (style_boho.css)
3. Update skill descriptions in `script.js`
4. Modify spacing/sizing in CSS variables

### Deploying:
1. Upload all files to web server
2. Ensure images are in same directory
3. Test on multiple browsers
4. Verify responsive design on mobile
